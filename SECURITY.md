# Security policy

AI Learning is an educational document repository, not an AI service and not
a production security guide. Examples may discuss sensitive domains such as
healthcare, finance, and security; they are not operational advice.

The LaTeX build uses `-shell-escape` for `minted` and SVG conversion. Build
only reviewed sources in an isolated workspace and do not place credentials,
private research material, personal data, or model/API keys in the repository.

Report security concerns privately through the
[bnaard GitHub profile](https://github.com/bnaard) with the affected path,
commit, safe reproduction steps, and suggested mitigation. Do not publish
secrets or an unpatched exploit in an issue.
